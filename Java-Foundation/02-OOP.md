## Java Source Code in Android

Android applications use Java classes to implement application logic.

The Java source code is located inside the project's `java` directory.

For example:

`MainActivity.java`

is a Java class used to implement the behavior of the main Activity.

The basic structure is:

Java Class
↓
Application Logic
↓
Android Framework APIs
↓
Android Application

Java code also works with Android resources through generated resource references such as:

`R.layout.activity_main`

This connects Java application logic with XML resources.
